# DSH 行情皮肤重构计划

## 已确认目标

- 面向本机 DSH Desktop 2.0.5 / Harness 0.1.2-rc.1 的标准插件，网页与桌面共用。
- 紧凑三栏终端风格，保留宿主会话与输入功能。
- 当前项目的实际代码行数作为 K 线纵轴；每次有证据的 Agent 修改形成记录。
- 删除 10,000 行显示真实长绿柱，恢复作为新的红柱；不重写历史。
- 成交量为新增与删除行数之和；排除依赖、构建产物和二进制。
- Token 分类、总计和历史持久保存，删除会话不删除统计，支持独立清理。
- 同一宿主上的网页与桌面共用统计；已有历史只按可验证记录回填。

## 架构

`src/core` 负责不可变统计记录、去重、按项目聚合和 K 线周期聚合。
`src/host` 使用宿主会话事件和文件差异收集证据，保存账本并提供查询。
`src/client` 使用正式主题与插槽 API，渲染 K 线和统计，保留原宿主工作流。
本地预览使用同一界面与独立测试项目生成的真实变更数据，明确标记预览。
